" 1. 标签页切换：h/l 向左/右切标签
unmap h
unmap l
map h previousTab
map l nextTab

" 2. 历史记录导航：Shift+J/K 后退/前进
unmap J
unmap K
map J goBack
map K goForward

" 3. 标签页位置移动：逗号向左，句号向右
map , moveTabLeft
map . moveTabRight

" 4. 书签打开：b 新标签页，B 当前标签页
unmap b
unmap B
map b Vomnibar.activateBookmarksInNewTab
map B Vomnibar.activateBookmarks

" 5. 网址/搜索：o 新标签页，O 当前标签页
unmap o
unmap O
map o Vomnibar.activateInNewTab
map O Vomnibar.activate

" 6. 文本选择：i 替代 yv 进入选择模式
unmap i
map i LinkHints.activateSelect
map yp copyWindowInfo type="tab" format="[${title}](${url})"
mapKey <H:v> <0>
mapKey <L:v> <$>
mapKey <J:v> <5j>
mapKey <K:v> <5k>
